# Baseline — iPhone wellness prototype

Baseline is an original, mobile-first web app prototype inspired by the public feature categories in The Coach's App Store listing. It does not use The Coach's branding, code, images, or private program content.

## Run on iPhone

1. Upload the files in this folder to a static host that serves the site over HTTPS.
2. Open the hosted `index.html` in Safari on iPhone.
3. Tap **Share → Add to Home Screen**, enable **Open as Web App** if shown, then tap **Add**.
4. Open Baseline once while online. The service worker caches the app shell for later offline use.

## Included

- Daily dashboard and locally saved check-ins
- Flexible movement menu, breathing reset, private reflections, and progress summary
- Pelvic-health safety information and a timer that runs only after the user confirms they have clinician-provided timing
- Optional private digital / sexual-content habit reflection
- Local JSON export and delete-data controls

## Limits

This is a browser prototype, not a signed iOS app or medical device. It does not provide diagnosis, individualized treatment, push reminders, account sync, Screen Time controls, or the original app's paid lessons and full workout library. Data remains in this browser on this device; clearing site data can remove it. Pelvic-health guidance in the prototype links to Cleveland Clinic information; persistent or concerning symptoms should be discussed with a qualified clinician.
